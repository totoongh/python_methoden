Genau dafür gibt es Funktionen. Eine Funktion ist ein eigener Befehl, den ihr selbst schreibt. Ihr gebt ihm einen Namen und könnt ihn danach so oft benutzen, wie ihr wollt. Wollt ihr etwas ändern, ändert ihr es nur an einer Stelle.
Vielleicht habt ihr auch schon das Wort Methode gehört. In Python ist eine Methode eine Funktion, die zu einem Wert gehört und mit einem Punkt aufgerufen wird, zum Beispiel alter.isdigit(). Hier schreibt ihr erst einmal ganz normale Funktionen.
In Teil 1 bis 3 lernt ihr, wie man Funktionen schreibt. In Teil 4 verbessert ihr damit das Programm aus Teil 0.

Teil 1: Die erste eigene Funktion

Tippt das folgende Programm ab oder kopiert es. Führt es dann aus.

def begruessung():
    print("Hallo!")
    print("Willkommen im Kurs.")

begruessung()
begruessung()

So lest ihr das Programm: Die Zeile mit def sagt Python: „Ich bringe dir jetzt einen neuen Befehl bei. Er heißt begruessung.“ Die eingerückten Zeilen darunter gehören zu diesem Befehl. Mit begruessung() wird der Befehl dann benutzt. Man sagt dazu: Die Funktion wird aufgerufen.

  1. Wie oft steht „Hallo!“ in der Ausgabe? Warum genau so oft?
  2. Löscht die beiden letzten Zeilen (begruessung()) und startet das Programm noch einmal. Was passiert jetzt? Erklärt, warum. Macht die Änderung danach wieder rückgängig.
  3. Nehmt bei print("Hallo!") die Einrückung weg, sodass die Zeile ganz links steht. Was passiert? Was sagt euch das über die Einrückung? Macht auch diese Änderung danach wieder rückgängig.
  4. def ist eine Abkürzung für ein englisches Wort. Findet heraus, für welches. Tipp: Es hat mit dem deutschen Wort „definieren“ zu tun.

Teil 2: return oder print?

Hier seht ihr zwei Funktionen, die fast gleich aussehen. Die erste benutzt print(), die zweite return.

Wichtig: Führt den Code noch nicht aus. Überlegt erst, was ausgegeben wird, und schreibt eure Vermutung als Kommentar auf. Führt ihn erst danach aus und vergleicht.

def quadrat_a(x):
    print(x * x)

def quadrat_b(x):
    return x * x

a = quadrat_a(4)
b = quadrat_b(4)
print("a:", a)
print("b:", b)
print(quadrat_b(3) + quadrat_b(2))
  1. Stimmt eure Vermutung? Was war anders als gedacht?
  2. Bei a steht None. None bedeutet in Python „nichts“. Warum hat a keinen Wert bekommen, b aber schon?
  3. Erklärt in eigenen Worten den Unterschied: print() zeigt etwas auf dem Bildschirm an. Was macht return?
  4. Schreibt in quadrat_b unter die Zeile mit return noch ein print("Fertig"). Wird „Fertig“ angezeigt? Was lernt ihr daraus über return?

Teil 3: Wo gilt eine Variable?

Führt dieses Programm aus. Achtung: Es wird mit einer Fehlermeldung enden. Das ist Absicht.

def verdopple(x):
    ergebnis = x * 2
    x = 100
    return ergebnis

zahl = 5
print(verdopple(zahl))
print(zahl)
print(ergebnis)
  1. Welcher Wert wird für zahl ausgegeben? In der Funktion steht doch x = 100. Hat das den Wert von zahl verändert?
  2. Die letzte Zeile erzeugt eine Fehlermeldung. Schreibt die Fehlermeldung ab und erklärt sie. Die Variable ergebnis gibt es doch in der Funktion. Warum kennt Python sie hier nicht?

Teil 4: Selbst Funktionen schreiben

Schreibt die folgenden Funktionen. Ruft jede Funktion mindestens dreimal mit verschiedenen Werten auf und gebt das Ergebnis mit print() aus. So prüft ihr, ob sie richtig funktioniert. Probiert auch Sonderfälle aus, zum Beispiel 0 bei Zahlen oder einen leeren Text "" bei zaehle_vokale. Ausnahme: lies_zahl testet ihr, indem ihr beim Ausführen verschiedene richtige und falsche Eingaben tippt.

Alle Funktionen sollen ihr Ergebnis mit return zurückgeben, nicht selbst mit print() ausgeben.

  1. ist_gerade(zahl) prüft, ob eine Zahl gerade ist. Sie gibt True oder False zurück.
    Beispiel: ist_gerade(4) ergibt True, ist_gerade(7) ergibt False.
    Tipp: Der Operator % gibt den Rest einer Division. 7 % 2 ergibt 1, denn 7 geteilt durch 2 ist 3 Rest 1.
  2. maximum(a, b, c) bekommt drei Zahlen und gibt die größte zurück. Benutzt dafür if, nicht den fertigen Befehl max().
    Beispiel: maximum(3, 9, 5) ergibt 9.
  3. summe_bis(n) rechnet alle Zahlen von 1 bis n zusammen.
    Beispiel: summe_bis(4) ergibt 10, denn 1 + 2 + 3 + 4 = 10.
  4. fakultaet(n) multipliziert alle Zahlen von 1 bis n miteinander.
    Beispiel: fakultaet(5) ergibt 120, denn 1 · 2 · 3 · 4 · 5 = 120.
    Achtung: fakultaet(0) ergibt in der Mathematik 1.
  5. zaehle_vokale(text) zählt, wie viele Vokale (a, e, i, o, u) in einem Text vorkommen.
    Beispiel: zaehle_vokale("Banane") ergibt 3. Großbuchstaben zählen auch: zaehle_vokale("Auto") ergibt 3.
  6. lies_zahl(frage, minimum, maximum) stellt eine Frage mit input(). Sie fragt so lange nach, bis eine ganze Zahl zwischen minimum und maximum eingegeben wird. Dann gibt sie diese Zahl als int zurück.
    Beispiel: alter = lies_zahl("Wie alt bist du? ", 6, 99)
    Tipp: Schaut euch an, wie die Schleifen in Teil 0 aufgebaut sind.
  7. Eine Funktion darf eine andere Funktion benutzen. Schreibt zuerst ist_teilbar(a, b). Sie gibt True zurück, wenn a ohne Rest durch b teilbar ist (Tipp: wieder %). Schreibt danach ist_schaltjahr(jahr) und benutzt darin ist_teilbar.
    Regel: Ein Jahr ist ein Schaltjahr, wenn es durch 4 teilbar ist. Ausnahme: Ist es durch 100 teilbar, ist es kein Schaltjahr. Ausnahme von der Ausnahme: Ist es durch 400 teilbar, ist es doch ein Schaltjahr.
    Beispiel: 2024 ja, 1900 nein, 2000 ja.

Teil 5: Projekt Zahlenraten zu zweit

Ihr programmiert ein Ratespiel für zwei Personen. So läuft es ab:

  1. Person A gibt eine geheime Zahl zwischen 1 und 100 ein.
  2. Danach gibt das Programm 50 leere Zeilen aus. So rutscht die Zahl nach oben aus dem Bild und Person B kann sie nicht sehen.
  3. Person B rät. Nach jedem Tipp sagt das Programm „zu groß“, „zu klein“ oder „richtig“.
  4. Wenn die Zahl erraten ist, zeigt das Programm an, wie viele Versuche Person B gebraucht hat.

Vorgabe: Schreibt das Programm mit Funktionen. Ganz unten steht dann nur noch ein kurzer Hauptteil, der die Funktionen aufruft. Diese Funktionen braucht ihr:

  • lies_zahl(frage, minimum, maximum): Die habt ihr schon aus Teil 4. Kopiert sie einfach herein.
  • verdecke_bildschirm(): gibt 50 leere Zeilen aus.
  • bewerte_tipp(tipp, geheim): vergleicht den Tipp mit der geheimen Zahl und gibt "zu groß", "zu klein" oder "richtig" zurück.
  • spiele_runde(): spielt eine ganze Runde und gibt am Ende die Anzahl der Versuche zurück.

Erweiterung: Nach jeder Runde fragt das Programm: „Nochmal? (j/n)“. Bei j startet eine neue Runde. Das Programm merkt sich die beste Runde, also die mit den wenigsten Versuchen, und zeigt sie am Ende an.

Teil 6: Zusatzaufgaben für Schnelle

  • Standardwerte: Man kann Parametern einen Wert vorgeben, der benutzt wird, wenn man nichts angibt. Beispiel: def lies_zahl(frage, minimum=1, maximum=100):
    Probiert aus, was passiert, wenn ihr lies_zahl("Zahl? ") ohne minimum und maximum aufruft.
  • Primzahlen: Schreibt ist_primzahl(n). Eine Primzahl ist nur durch 1 und sich selbst teilbar (zum Beispiel 2, 3, 5, 7, 11). Die 1 ist keine Primzahl. Schreibt danach gib_primzahlen_aus(bis), die alle Primzahlen bis zu einer Zahl ausgibt. Benutzt darin ist_primzahl.
  • Rekursion: Eine Funktion kann sich auch selbst aufrufen. Sucht nach „Python Rekursion Fakultät“ und schreibt fakultaet(n) ein zweites Mal, diesmal ohne Schleife.
  • Mehrere Rückgabewerte: Mit return a, b gibt eine Funktion zwei Werte zurück. Schreibt min_und_max(a, b, c), die die kleinste und die größte Zahl zurückgibt, ohne min() und max() zu benutzen. Probiert aus: klein, gross = min_und_max(4, 9, 1)
